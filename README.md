# CS_300_Data_Stractures_and_Algorithms

## Project Overview

This repository contains my work from CS 300: Data Structures and Algorithms. It includes an analysis of runtime and memory efficiency for different data structures and a C++ application designed to organize and display computer science course information.

## Reflection

**What was the problem you were solving in the projects for this course?**

The main goal of these projects was to develop a program that could efficiently organize, store, and display course information for the Computer Science program at ABCU. This included reading course data from a file, sorting courses in alphanumeric order, and allowing users to search for specific courses and view their prerequisites. I also needed to evaluate different data structures to determine which would be the most efficient for the program.

**How did you approach the problem? Consider why data structures are important to understand.**

I approached the problem by breaking down the requirements and developing pseudocode before implementing the program in C++. I compared vectors, hash tables, and binary search trees to better understand their advantages, disadvantages, and runtime efficiency. This helped me recognize how important choosing the appropriate data structure is because it directly affects a program's performance, organization, and ability to handle larger amounts of data.

**How did you overcome any roadblocks you encountered while going through the activities or project?**

One of the biggest challenges was making sure the different functions worked together correctly while keeping the code organized and readable. I worked through these challenges by reviewing my logic, troubleshooting errors, and testing the program as I completed each section. Breaking the project into smaller tasks made it easier to identify problems and correct them without becoming overwhelmed by the entire program.

**How has your work on this project expanded your approach to designing software and developing programs?**

These projects helped me understand the importance of planning and evaluating different approaches before beginning development. Rather than focusing only on whether a program works, I now consider how efficiently it operates and whether the design makes sense for its intended purpose. I have also gained a better understanding of how algorithms and data structures influence software design decisions.

**How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?**

Throughout this course, I became more intentional about writing code that is organized, readable, and easier to maintain. Using clear function names, consistent formatting, and smaller functions helped make the program easier to understand and troubleshoot. Moving forward, I want to continue applying these practices so that my programs are not only functional but can also be updated or expanded without unnecessary complications.
